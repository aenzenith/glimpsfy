Glimpsfy reads the text inside a selection and puts it on the clipboard in one
step. The recognition runs on this Mac, so no image ever leaves the machine,
and the result keeps the order in which a person would read the page.

Multi-column articles, tables and code are the hard cases. A screenshot of a
terminal keeps its indentation, a table keeps its rows, and a hyphenated word
at the end of a line is joined only when that is safe: the engine checks each recog-
nition result against the width of its column before it removes the hyphen.
